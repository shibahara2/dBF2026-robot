# 会場UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a self-service kiosk screen (`GET /`) that lets a guest check
in and watch AI管制PF/R2 progress via the existing SSE endpoint, with zero
changes to the backend state machine or clients.

**Architecture:** A Flask template (`app/templates/index.html`) served by a
new `ui_bp` Blueprint renders a single-page shell with three sections (form /
progress / error). A vanilla-JS file (`app/static/app.js`) subscribes to
`/api/events` via `EventSource` and shows/hides those sections purely based
on the snapshot's `phase`/`step`/`guest_name` — no new backend state, no
polling, no client-side "delivery complete" inference.

**Tech Stack:** Flask templates (Jinja2), vanilla JS (`EventSource`, `fetch`),
plain CSS. No build tooling, no JS test framework (matches existing repo,
per spec's YAGNI call).

**Spec:** `docs/superpowers/specs/2026-09-13-venue-ui-design.md`

## Global Constraints

- Do not modify `app/state_machine.py`, `app/routes/checkin.py`,
  `app/routes/events.py`, or any client under `app/clients/` — the spec
  requires zero backend changes.
- Do not implement any "delivery complete" detection or toast — display only
  the raw `phase`/`step`/`error_message` values from the snapshot.
- Do not show `guest_name` for another guest's in-progress cycle — only for
  the viewer's own (tracked via `sessionStorage`).
- No new JS/Node test tooling — JS is verified by manual browser check per
  the spec's testing section.
- Step message strings (verbatim, must match exactly):
  - `polling_pf_ready` → `AI管制PF(案内ロボット)の状態を確認しています`
  - `polling_r2_ready` → `ドリンク準備ロボットの状態を確認しています`
  - `sending_load_drink` → `ドリンクをセットしています`
  - `polling_r2_active` → `ドリンクをお届け中です`
  - `notifying_pf_placed` → `お届け完了を通知しています`

default to `app/templates` and `app/static` — the same resolution
`app/__init__.py`'s `Flask(__name__)` gets in production.

- [ ] **Step 1: Write `app/static/app.js`**

```js
const STEP_MESSAGES = {
  polling_pf_ready: "AI管制PF(案内ロボット)の状態を確認しています",
  polling_r2_ready: "ドリンク準備ロボットの状態を確認しています",
  sending_load_drink: "ドリンクをセットしています",
  polling_r2_active: "ドリンクをお届け中です",
  notifying_pf_placed: "お届け完了を通知しています",
};

const formView = document.getElementById("form-view");
const progressView = document.getElementById("progress-view");
const errorView = document.getElementById("error-view");
const checkinForm = document.getElementById("checkin-form");
const guestNameInput = document.getElementById("guest-name-input");
const progressMessage = document.getElementById("progress-message");
const errorMessage = document.getElementById("error-message");
const resetButton = document.getElementById("reset-button");

function getMyGuestName() {
  return sessionStorage.getItem("myGuestName");
}

function setMyGuestName(name) {
  sessionStorage.setItem("myGuestName", name);
}

function render(snapshot) {
  formView.hidden = true;
  progressView.hidden = true;
  errorView.hidden = true;

  if (snapshot.phase === "error") {
    errorMessage.textContent = snapshot.error_message;
    errorView.hidden = false;
    return;
  }

  if (snapshot.step === "awaiting_checkin") {
    formView.hidden = false;
    return;
  }

  const stepMessage = STEP_MESSAGES[snapshot.step] || "";
  if (snapshot.guest_name === getMyGuestName()) {
    progressMessage.textContent = stepMessage;
  } else {
    progressMessage.textContent = "他の方が対応中：" + stepMessage;
  }
  progressView.hidden = false;
}

checkinForm.addEventListener("submit", (event) => {
  event.preventDefault();
  const name = guestNameInput.value.trim();
  if (!name) {
    return;
  }
  setMyGuestName(name);
  fetch("/api/checkin", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ name: name }),
  });
});

resetButton.addEventListener("click", () => {
  fetch("/api/reset", { method: "POST" });
});

const eventSource = new EventSource("/api/events");
eventSource.onmessage = (event) => {
  render(JSON.parse(event.data));
};
```
